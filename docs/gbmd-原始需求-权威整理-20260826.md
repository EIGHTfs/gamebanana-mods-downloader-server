## 六、下载功能（完全重新写，旧代码仅供参考）

### 第一步：生成 HTML
- 输入：香蕉网 mod 地址 `https://gamebanana.com/mods/704164` 或纯数字 `704164`
- 功能：根据网页生成 HTML 文件
- HTML 记录内容包括：
  ```
  Genshin Impact/Mods/Skins/Characters/Sandrone
  游戏 = Genshin Impact，Skins 映射为空，Characters = 角色，Sandrone = 桑多涅
  ```
- 下载路径 = `gamebanana.com.json` 中 Genshin Impact 的下载路径 + `/角色/Sandrone – 桑多涅/`
- **注意**：角色名 Sandrone 映射为桑多涅，**却不是直接是「桑多涅」文件夹**，所有角色名映射都按 `英文 – 中文` 示例
- HTML 可见部分结构：
  ```html
  <body>
    <h1>Sandrone NSFW</h1>
    <p class="meta">
      作者：<strong>PaimonTaxCollector</strong><br>
      游戏：Genshin Impact　分类：Sandrone / Characters<br>
  ```
- 完整下载路径 = 游戏下载路径 + `/角色/Sandrone – 桑多涅/` + `[PaimonTaxCollector] Sandrone NSFW`
- HTML 文件内容包括：**文件列表记录压缩包 md5、图片名、gif**
  - 图片名：**真实图片图片名本身就是 md5 值**，而预览图不是
- **不改原始文件名**，除非文件名含 Windows/Linux 非法字符 → 用空格替换

### 第二步：查重归位
- 计算出正确下载路径后，先判断欲下载文件是否存在
- 整个游戏根目录范围搜索**压缩包名、图片名**
- 找到是否存在于其他文件夹：
  - **所有文件夹**（不在仓库目录）
  - 如找到的文件**在仓库目录** → 移动文件本身
  - 若存在 → 直接 `mv` 此文件夹为计算出的完整下载路径（文件夹内全部文件完整保留）
- HTML 存于此文件夹（若原有 HTML 则**覆盖原有 HTML**）

### 第三步：整理阶段
- 通过 HTML 检查文件完整性：
  1. 同名 `.gbmd.part` 处理：`1.zip` 和 `1.zip.gbmd.part` 都存在 → 删 part
  2. 仅 `1.zip.gbmd.part` 存在（无 1.zip）→ 未下载完，支持断点续传
  3. 文件夹内**全部图片重命名为图片 hash 值**，不保留重复图片，重复的移动进根目录垃圾桶文件夹

### 第四步：正式下载
- 按 HTML 文件列表下载缺失文件（并发、断点续传、重试、跳过）

### 测试要求（纯 API 调用）
- 搜索「桑多涅」→ 能实现搜索到 Sandrone
- 下载所有 Sandrone 的 NSFW，看能否下载前先重命名规范文件夹名 `Sandrone – 桑多涅`
- 找到文件路径不对的已下载文件 → 实现正式下载时跳过这些文件

## 八、网页功能要求

### 下载功能按钮（确保按了能调用）
- 暂停、继续、终止、重试失败
- 并发数修改
- 下载列表：**每组 mod 一组**出现在下载列表，**只有下载完了整组移除**任务列表不再显示
- **跳过的图片也显示预览图**在下载列表

### 配色/主题
- 原来那种配色（类似香蕉网）保留作为**夜间模式**
- 现在这种蓝白色是**白天模式**
- 网页支持切换
- **白天模式字体本身是暗色，夜间模式字体本身是亮色**

### 选项卡调整
- 原 5 个：下载、搜索、文件夹合并、下载进度、设置
- 改为 4 个：**下载、下载进度、搜索、设置**
- **文件夹合并放设置里面**

### 并发数位置
- 设置里面不要并发数了
- **下载进度的并发数保留**，只要这一个位置改

## 十一、文件名规则（最终定稿）

- **所有文件名按 GB 原名**（压缩包、图片、gif）
- gif **不强求**：下载失败自动跳过（**不显示失败在 UI，直接跳过**）
- HTML 实现**只显示下载完成的**，和**追加旧文件**（香蕉网上没有的文件，但实际存在的旧 mod、图片）
